# JarCritter

ペットと一緒に、楽しみながら貯金を習慣にする Android 向け家計簿アプリ。

ペットにごはんやおもちゃを「買う」と、その金額がそのまま貯金になります。家計簿で毎月の余りを生み出し、日々の小さな貯金でペットを育てる、という流れを目指しています。
