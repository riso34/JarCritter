# 家計簿アプリ デザインガイドライン（統一要素）

最終更新：2026年11月11日

## 全体の方向性
- シンプルで落ち着いた雰囲気。
- Material Design 3 に沿った操作感（Android のみのため）。
- Android 12 以降の「壁紙に合わせた配色（ダイナミックカラー）」は使わず、決めた配色で固定する。

## 色彩

| 用途 | 方針 |
|---|---|
| メインカラー | 青みと深みのある落ち着いた緑（例：#2E7D5B 前後）。ボタン、選択中のタブ、進み具合のバーなど「操作できる場所・選択中の場所」に使う。 |
| 収入 | 緑。メインカラーより明るく黄みのある緑にして、ボタンの緑と区別する。 |
| 支出 | 落ち着いた赤。 |
| 警告 | 鮮やかな赤。予算超過、使いすぎ警告、エラー、削除ボタンのみに使用。必ずアイコンか文字を添える。 |
| カテゴリ用 | 彩度を抑えた 10〜12 色。円グラフで隣り合っても区別できるよう色相を均等に散らす。 |

**ルール**
- 色だけで情報を区別しない。収入・支出には必ず符号（＋／−）を付ける（赤と緑は色覚の特性によって見分けにくい組み合わせのため）。
- 赤は普段の画面に多用せず、「赤が出たら注意が必要」と分かるようにする。

## ダークモード
- 端末の設定に合わせて切り替える。
- すべての色にライト用とダーク用の値を持たせる。
- 背景は真っ黒ではなく濃いグレー（#121212 前後）。
- 緑やカテゴリ色はダーク時に少し明るくして見やすさを保つ。

## 見た目
- 角の丸み：小さめ（4dp 前後）。Material Design 3 の標準より小さく調整する。
- アイコン：線で描くスタイルで統一。Material Symbols の Outlined を想定（下部タブ、カテゴリアイコンなどすべて）。

## 文字フォント
- 日本語フォント：Noto Sans JP をアプリに組み込む（端末メーカーによる見た目の違いをなくすため）。
- 太さ：標準・中太・太字の 3 段階程度に絞る。
- 文字の大きさ：端末の文字サイズ設定に合わせる。拡大時は金額を最優先で表示し、はみ出す場合はメモを省略する。文字サイズ最大の状態でもデザインを確認する。

## 金額の表示
- 形式：「1,234円」（3 桁ごとにカンマ）。
- 符号：収入は「+300,000円」、支出は「−1,234円」。
- 数字は等幅数字を使い、一覧で桁をそろえる。
- グラフの目盛りなど狭い場所のみ「30万円」などの省略表記を使う。
