# JarCritter アプリ概要

最終更新：2026年11月13日

| 項目 | 内容 |
|---|---|
| アプリ名 | JarCritter（ジャークリッター）。「瓶に住む生き物」の意味。ストア表示名は「JarCritter - ペットと貯める家計簿」のように説明を添える想定 |
| 対象ユーザー | 一般公開（不特定多数の個人ユーザー） |
| プラットフォーム | Android のみ |
| 収益化 | 広告ありの無料（将来、有料プランを検討。ペットやアイテムの課金販売はしない） |
| データ保存 | クラウド保存（ユーザーアカウントに紐づく） |
| ログイン | 必須（Google／メールアドレス＋パスワード） |

## コンセプト

**一言で：「ペットと一緒に、楽しみながら貯金を習慣にする」**

- **貯金を習慣づけることが目的**：月に一度まとめて貯めるのではなく、日々数百円ずつ「貯金する」という行動を重ねる。
- **貯金を「使う楽しさ」と結びつける**：我慢として貯めるのではなく、ペットのお世話や楽しみに向かって貯める。
- **家計簿は土台**：記録・予算・グラフは、余りを生み出して貯金に回すための仕組みとして残す。記録は最短（金額 → カテゴリ → 保存）で済むようにする。
- **責めない**：貯金できない日や赤字の月があっても、ペットが弱ったり、それまでの貯金が消えたりしない。

## テーマ：仮想ペットの育成

### 基本の仕組み
- ペットにごはんやおもちゃを「買う」と、その金額がそのまま貯金になる。
- アプリ上の貯金はお金を動かさない（口座とは連携しない）。実際のお金は、月に一度ユーザーが自分で貯金口座へ移す（下記「お金を実際に移す仕組み」）。
- アプリ名のとおり、「貯金瓶の中でペットが暮らしている」という世界観にする。

### アイテム
買った金額がそのまま貯金額になる。少額は毎日、高額はたまに、という流れを作る。

| 種類 | 金額の目安 | 性質 |
|---|---|---|
| ごはん・水 | 100円前後 | 消えるもの。毎日のお世話 |
| おやつ | 200〜300円 | 消えるもの。多めに貯金できた日のご褒美 |
| おもちゃ | 300〜500円 | 残るもの。遊ぶ姿が見られる |
| 家具・おうち | 1,000円〜 | 残るもの。部屋が少しずつ豪華になる |

- 消えるもの（ごはん）で毎日の習慣を、残るもの（おもちゃ・家具）で積み重ねの実感を出す。
- ペットごとに好きなごはんやおもちゃを変え、個性を出す。

### ペット
- **最初の 1 匹は無料**：初期設定で数種類から選ぶ（例：犬・猫・うさぎ・ハムスター）。
- **2 匹目からは貯金で迎える**：値段がそのまま貯金額になる。珍しいペットほど高めにする（例：インコ 3,000円、ハリネズミ 5,000円、カワウソ 10,000円）。
- **お迎え予約**：迎えたいペットを予約し、日々の小さな貯金で少しずつ近づく。予約中のペットは影や卵の姿で部屋に見え、「あと○円でお迎え」と表示する。貯まったらお迎えの演出とともに部屋にやってくる。
- 種類の候補：定番（犬、猫）、小動物（うさぎ、ハムスター、インコ、カメ）、少し珍しい（ハリネズミ、フクロウ、カワウソ）。

### 1 匹でも複数でも楽しめる形
- **相棒を 1 匹選ぶ**：ホームに出るのは選んだ 1 匹だけ。1 匹を長く育てたい人はずっと同じ相棒でよい。
- **ほかの子は部屋で暮らす**：部屋の画面で全員の様子を見られる。
- **ごはんは渡したい子に**：1 回の貯金でごはんをあげるのは 1 匹。あげなかった子が弱ることはない。
- **家具・おもちゃは共有**：部屋に置いたものは全員で使える。

### 責めない設計
- ペットはお腹をすかせて弱ったり、死んだりしない。お世話がない日が続いても、眠っているだけにする。

### お金を実際に移す仕組み
- アプリ上の貯金と実際の口座がずれていくことを隠さず、次の 2 つを分けて表示する。
  - ペットに使った額（まだ口座に移していない額）
  - 移し済みの額
- **月 1 回の「お引越し」**：月初に「今月のごはん代 ○円を貯金口座に移しましょう」と案内し、ユーザーが銀行アプリなどで移したらチェックする。チェックするとペットが新しい部屋に引っ越すなどのご褒美を付け、実際にお金を動かす瞬間をいちばん嬉しい場面にする。
- 現金派の人は、実物の貯金箱に入れたらチェックする形も選べる。

### ペットの動き
- リリース時はルールで動かす（時間帯で寝る・起きる、おもちゃで遊ぶ、歩き回るなど）。AI による会話などは将来の検討事項（05 を参照）。

### リリース時の範囲
- 絵の量が増えすぎないよう、最初は「ペット 4 種類 × 成長 3 段階」程度に絞る。おもちゃ・家具は全ペット共通にする。

## 競合との違い
- 自動貯金アプリ（finbee など）は銀行口座と連携して実際にお金を動かす。本アプリは口座と連携せず、日々の貯金を「お世話」として楽しくする点で異なる。
- ペット育成型の家計簿（Moneypet など）は「記録するとごはんがもらえる」。本アプリは「ごはんを買うことがそのまま貯金になる」点で異なる。
